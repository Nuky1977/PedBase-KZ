## Жоба туралы

PedBase KZ – аудандық және қалалық білім бөлімдеріне арналған педагогтарды басқарудың бірыңғай ақпараттық жүйесі.

Жүйенің негізгі мақсаты:

- педагогтар туралы мәліметтерді бір жерде сақтау;
- Excel арқылы мәлімет жинауды тоқтату;
- есептерді автоматты қалыптастыру;
- педагогтың толық электрондық іс қағазын жүргізу.
