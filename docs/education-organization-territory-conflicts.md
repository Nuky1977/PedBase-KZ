# Білім беру ұйымдарының аумақтық сәйкестіктері

Бұл есеп негізгі `pedbase_kz` схемасының 396-қадамда алынған және оқшауланған MySQL 8.4.3 схемасына қалпына келтірілген көшірмесіне негізделген. Тексеру тек жиынтық сандарды пайдаланды.

| Тексеру | Саны |
| --- | ---: |
| Бұрынғы аудандар мен қалалар | 0 |
| Мектептер | 0 |
| Бір атауға келетін аудан топтары | 0 |
| Ауданы көрсетілмеген мектептер | 0 |
| Қайталанған БСН топтары | 0 |
| Жарамсыз немесе бос БСН | 0 |
| Педагог–мектеп бекітулері | 0 |
| Негізгі және қосымша бекітулер | 0 / 0 |
| Бірнеше негізгі орны бар педагогтер | 0 |
| Бекітілген, бірақ негізгі орны жоқ педагогтер | 0 |
| Мектепке не пайдаланушыға байланысы үзілген бекітулер | 0 |
| Педагог рөліне жатпайтын бекітулер | 0 |

## Сәйкестендіру ережесі

1. Бұрынғы `districts` кестесі ауданның атауын және ішкі ID-ін сақтайды. Облыс пен аудан/қала түрін анықтауға атаудың өзі жеткіліксіз. Жаңа каталогта алдымен облыс коды, кейін оған тиесілі тұрақты аудан/қала коды бекітіледі.
2. Сәйкестік расталғаннан кейін ғана бұрынғы `districts.id` мәніне жаңа `education_areas.code` бекітіледі. Бірдей атаулар бос орындар қысқартылып, әріп регистрі ескерілмей алдын ала белгіленеді. Әртүрлі облыстағы аттас аумақтар облысы мен коды бойынша ажыратылады. Бір кодты екі бұрынғы ауданға берер алдында оның бір аумақтың қайталанған жазбасы екені қолмен расталады.
3. Мектептің сәйкестігі бұрын бекітілген `legacy_school_id`, одан кейін БСН бойынша қаралады. Қайшылық болса, атау тек қолмен тексеруге көмек береді. БСН, аудан немесе елді мекен расталмаса, мектеп автоматты көшірілмейді.
4. Нақты деректер пайда болғанда даулы жолдар қорғалған есепте бұрынғы мектеп ID-і, аудан ID-і, ұсынылған код, қайшылық себебі және бекіту күйі бойынша тіркеледі. Аумақ картасы бекітілген соң dry-run қайта орындалады.

Осы көшірмеде даулы жол жоқ. Аумақ сәйкестік картасы бос, өйткені байланыстыратын бастапқы аудан мен мектеп жазбасы болған жоқ.
