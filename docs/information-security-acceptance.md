# PedBase-KZ ақпараттық қауіпсіздікті қабылдау парағы

**Жоба.** Орта ___ · Бекітілетін SHA ___ · Тексеру күні ___ · Хаттама нөмірі ___.

Әр тармаққа тексерілген орта, уақыт, рөл және құпиясыз дәлел идентификаторы енгізіледі. Төмендегі өндірістік тармақтар ашық.

| Бақылау | Өту критерийі | Жауапты және дәлел |
| --- | --- | --- |
| ☐ SMTP ағыны және домен | Бекітілген Postmark транзакциялық ағынына байланған SMTP Token қоймадан енгізіледі. DKIM TXT, custom Return-Path CNAME, SPF сәйкестігі және DMARC сынақ хатта расталады. Сертификаты тексерілетін STARTTLS және бекітілген HTTPS хосты қолданылады. Деректі өңдеу орны мен сақтау мерзімін дерек иесі бекітеді. | Пошта/DNS әкімшісі ___ · Дәлел ___ |
| ☐ Хат және токен | Хат бекітілген жәшікке түседі. Жеткізілім оқиғасы хат идентификаторымен сәйкес. Сілтеме бір рет қолданылады. Қайта қолдану мен мерзімі өткен токен қабылданбайды. Relay, proxy, қолданба және APM журналдарында URL токені, құпия тіркелгі деректері және хат денесі жоқ. | Қауіпсіздік өкілі және пошта әкімшісі ___ · Дәлел ___ |
| ☐ Vault Agent және рөлдер | Agent токен файлын web root-тан тыс жазады, Laravel қызметі оқиды. TLS сенім тізбегі тексеріледі. Қолданба AES және HMAC-тың екі бөлек нұсқаланған KV v2 жолын оқиды. Осы рөлмен басқа жолды оқу, жазу және жою қабылданбайды. | Vault әкімшісі ___ · Дәлел ___ |
| ☐ Vault қалпына келтіру | Кілт әкімшісі нұсқалайды, аудитор тек рұқсатты метадеректі қарайды, қалпына келтіруші уақытша рұқсат алады. Snapshot бөлек ортаға қалпына келеді. Синтетикалық ciphertext ашылып, HMAC сәйкес келеді. Vault тоқтағанда ЖСН өзгерту және тазарту 503 қайтарып, жазба сақталады. | Vault әкімшісі, қалпына келтіруші, аудитор ___ · Дәлел ___ |
| ☐ Архив құқықтары | Көшірме жасаушы жаңа архив жазады, қалпына келтіруші оқиды, retention әкімшісі мерзімді басқарады. Артық оқу/жазу/жою тыйымдары нақты сақтау орнында тексеріледі. Қалпына келтіру кілті және сенімді SHA-256 манифесі архивтен бөлек. | Сақтау әкімшісі ___ · Дәлел ___ |
| ☐ Архив тұтастығы және PDF | Өндірістік сақтау орнынан синтетикалық пакет бөлек MySQL мен жабық PDF каталогына қайтарылады. SHA-256, CMS тегі және кесте бойынша жол саны сәйкес. Өзгертілген архив қабылданбайды. PDF құқығы бар рөлге ашылады, рұқсатсыз рөлге 403 қайтады. | Қалпына келтіру операторы және дерекқор әкімшісі ___ · Дәлел ___ |
| ☐ RPO/RTO және журнал | Дерек иесі бекіткен RPO ___ және RTO ___ нақты сақтау орнынан қалпына келтірумен расталады. Дәлелдерге хэштер, кілт нұсқасының идентификаторы, рөл және уақыт кіреді. | Дерек иесі және қауіпсіздік өкілі ___ · Дәлел ___ |
